- Screen sharing now uses the same kind of congestion control as Discord's own app: it watches for the network starting to queue up and backs off before packets are lost, so streams stop freezing. Packets are paced gently like Discord's, and keyframes only go out when a viewer asks (at most every half second) instead of every 3 seconds.
- Sharing a game window (Valorant and other borderless games) no longer shows a black screen: windows are now captured with Windows Graphics Capture on the GPU that runs the game, like Discord does.
- New: after restarting in a call, a green banner offers to reconnect you to your last voice channel, like Discord.
- New: when you're playing a game, a bar above your user panel shows it with a button to stream it.
- New: Nitro, Shop and Quests links under Friends, "Find or start a conversation" search, and a New Group DM button on the Friends page, like Discord.
